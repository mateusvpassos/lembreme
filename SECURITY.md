# Segurança

## Versões com correção

Só a versão mais recente recebe correções de segurança.

## Como reportar

**Não abra uma issue pública.** Use o reporte privado do GitHub: aba **Security → Report a vulnerability** ([link direto](https://github.com/mateusvpassos/lembreme/security/advisories/new)).

Inclua a versão do Lembreme e do Windows, os passos para reproduzir e o impacto. A resposta inicial vem em até 7 dias.

## Escopo

O Lembreme roda só no seu computador e não acessa a rede. Interessam principalmente:
- execução de código a partir do conteúdo de um lembrete ou do `lembretes.json`;
- problemas no instalador ou no atalho de inicialização.
